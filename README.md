# Sales & Profit Dashboard 📊

## About the Project
This project demonstrates data visualization using Python and Matplotlib. It creates a dashboard containing four different types of charts to visualize sales, profit, and score data.

## Features
- **Line Chart:** Displays monthly sales trends.
- **Scatter Plot:** Visualizes monthly profit.
- **Bar Chart:** Compares sales across different months.
- **Pie Chart:** Shows score distribution.
- **Dashboard Layout:** Combines four charts into one figure.
- **Save Dashboard:** Exports the dashboard as a PNG image.

## Technologies Used
- Python
- Matplotlib

## Dataset
The project uses sample data:

**Months:** January, February, March, April, May

**Sales:** 75, 50, 35, 85, 66

**Profit:** 34, 21, 13, 41, 32

**Scores:** 55, 34, 12

## Installation

Install Matplotlib:

```bash
pip install matplotlib
```

## Run the Project

```bash
python dashboard.py
```

The program generates a dashboard image named:

`dashboard.png`
